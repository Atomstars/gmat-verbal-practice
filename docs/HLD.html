Architecture · High-Level Design (HLD)

GMAT Trainer — system at a glance

The bird's-eye view: two independent halves — an offline data factory (Python) and a serverless browser app (React) — joined only by a set of static data files. This is what makes the product cost nothing to run and impossible to take down with a server outage.

Build time (offline, occasional) Runtime (browser, every session) Data artifacts (the seam) Cloud services (optional)

Fig 1 — High-level design. Arrows show data/usage flow. The green “deploy” arrow is the only link between the two halves: the pipeline's output files become the app's static data.
